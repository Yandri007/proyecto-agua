# 💧 AquaControl - Sistema de Gestión para Distribuidora de Agua

Sistema completo para gestión de pedidos, repartidores, inventario y administración de una distribuidora de agua. Incluye WebSockets para tiempo real, geolocalización estilo Uber, y dashboards interactivos.

## 📌 Requisitos Previos

Antes de empezar, asegúrate de tener instalado:

- **Node.js** (v18 o superior) → [Descargar](https://nodejs.org/)
- **PostgreSQL** (v14 o superior) → [Descargar](https://www.postgresql.org/download/)
- **Git** → [Descargar](https://git-scm.com/)
- Un editor de código (recomendado: VS Code)
